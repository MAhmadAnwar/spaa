# Serene Massage Website

A complete responsive massage/spa landing website built only with:
- HTML
- CSS
- Vanilla JavaScript

## Included
- Floating/sticky rounded navigation
- Responsive mobile menu
- Full-screen hero section
- CTA buttons
- Working smooth-scroll navigation
- Service cards
- Package cards
- About section with circular stamp
- Animated statistics counters
- Testimonial carousel with arrows/dots + touch swipe
- Monthly membership section
- Pricing plans
- "What you can expect" section
- Blog/journal layout
- Large CTA banner
- Location cards
- Contact form demo interaction
- Footer
- Back-to-top button
- Scroll reveal animations
- Hero/CTA image zoom + subtle parallax
- Reduced-motion accessibility support

## Run
Open `index.html` in a browser.

The demo uses remote Unsplash images and Google Fonts. Replace the image URLs in `index.html` and `style.css` with your own local assets if you want the website to work fully offline.

## Note
The layout and motion language are recreated from the supplied reference/video (rounded navigation, cream/blush palette, dark blue sections, card layouts, reveals, counters, slider, parallax). It is an original HTML/CSS/JS implementation rather than a copy of Squarespace's proprietary source code.
